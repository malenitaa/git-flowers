🌱 Git Flowers

Tu historial de commits, convertido en un jardín pixel que crece con vos.

Semilla (0 commits) Brote (1–3) Tallo (4–7) Flor / fruto (8+ o racha larga)
Los datos se obtienen del contribution graph público de GitHub vía una API de terceros de solo lectura, sin autenticación ni tokens. 100% front-end, sin backend propio. Código bajo licencia MIT.
